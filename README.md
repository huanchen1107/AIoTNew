# AIoTNew

Welcome to **AIoTNew**! This is a modern, production-ready project template designed to bootstrap web application development quickly.

## 🚀 Features

- **Clean Architecture**: Organized structure separating components, services, and assets.
- **Fast Development**: Configured with modern dev tools for hot reloading and quick feedback loops.
- **Ready to Go**: Built-in boilerplate configurations to get you coding instantly.

## 🛠️ Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/huanchen1107/AIoTNew.git
cd AIoTNew
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```

### 4. Build for Production
```bash
npm run build
```

## 📂 Project Structure

```text
├── src/                  # Source files
│   ├── components/       # UI Components
│   ├── styles/           # CSS/Styling
│   └── main.js           # Entry point
├── public/               # Static assets
├── package.json          # Dependency list
└── README.md             # Project documentation
```
